Metadata Providers

            
          

          

            CodexServer enriches each uploaded EPUB in priority order. The first
            provider that returns both title and author wins.

KOReader Users

            
          

          

            One user per e-reader. KOReader signs in with HTTP Basic Auth on
            /sync/*. KOReader password is independent from your
            admin password.
