Setup & Connect

Schritt-für-Schritt-Anleitung, um deine E-Reader mit CodexServer zu verbinden. Die URL unten ist automatisch auf deinen Server zugeschnitten.

Deine Server-URL & Zugangsdaten

Die Basis-URL wird automatisch aus der aktuellen Browser-Adresse ermittelt. Trag unten den Usernamen + Passwort eines KOReader-Users ein (Tab „Settings" → KOReader Users) — die Client-URLs weiter unten werden daraus live erzeugt.

Diese Zugangsdaten landen nirgends — sie werden nur im Browser zu den URL-Strings zusammengesetzt, damit du sie bequem kopieren kannst.

Moon+ Reader

OPDS-Katalog („Netz-Bibliothek") für den Buchbestand und WebDAV für die Sync-Dateien.

1 · OPDS-Katalog hinzufügen

  1. Moon+ Reader → Menü → Netz-Bibliothek → + (neuer Katalog).
  2. Name frei wählen, z. B. CodexServer.
  3. URL eintragen (Basic Auth ist in der URL codiert):

    Format: http://username:passwort@host:port/opds. Ersetze username und passwort durch die Zugangsdaten deines Logins (dein Username + Passwort).

  4. Speichern und öffnen — die Bibliothek listet alle Bücher.

2 · WebDAV-Sync einrichten

  1. Moon+ Reader → Einstellungen → Sync → WebDAV-Synchronisierung.
  2. Server-URL:
  3. Benutzername + Passwort: dieselben wie beim OPDS-Katalog.
  4. Sync-Richtung: Bilateral (empfohlen) — Positionen werden bidirektional gemergt.
  5. Im Buch: Lesezeichen/Position werden bei jedem Schließen automatisch hochgeladen.

KOReader

OPDS-Katalog für Downloads und KOSync (Custom Sync Server) für den Lesefortschritt.

1 · OPDS-Katalog hinzufügen

  1. KOReader → Hauptmenü (☰) → OPDS-Browser → +.
  2. URL:
  3. Benutzername + Passwort: dein Login.
  4. Speichern → Katalog öffnen → Bücher herunterladen.

2 · KOSync einrichten

  1. KOReader → ☰ → Fortschrittssynchronisation (Progress sync).
  2. Dort auf Custom sync server umschalten.
  3. Server-URL:
  4. Username + Passwort: dein Login.
  5. Test drücken — Server sollte „success" melden.
  6. Im Buch liest KOReader die Position beim Schließen automatisch hoch (nicht pro Seitenwechsel). Im Web-UI unter Settings → Sync Activity taucht der Eintrag mit blauem KOReader-Badge auf.
Hinweis: Nutze auf all deinen eigenen Geräten und Lese-Apps denselben Usernamen und dasselbe Passwort wie für dein Login, damit dein Lesefortschritt überall synchron bleibt.
